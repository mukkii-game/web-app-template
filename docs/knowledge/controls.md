# 操作の既定(キーボード&マウス・スマホ・コントローラ)

**どの作品も 3 つ全部で遊べるようにする。** 割り当ての既定は下の表で、`src/core/input.ts` が実装している。
作品で変える時は、この表を SPEC.md に写して直す(タイトル画面か一時停止に操作説明を出す)。

| 意味 | キーボード | マウス | スマホ(タッチ) | コントローラ(標準配置) |
|---|---|---|---|---|
| 移動 | 矢印 / WASD | — | 画面の左半分をドラッグ | 十字キー / 左スティック(0.4 以上傾けたら) |
| 決定・アクション | Space / Enter / Z / X | 画面の右半分をクリック | 画面の右半分をタップ | A / B |
| 一時停止 | Esc / P | (作品で ⏸ ボタンを置く) | (作品で ⏸ ボタンを置く) | START |
| 調整パネル | F2 | — | 画面左上を 3 回タップ | — |

決まり:
- 「押した」は押した瞬間だけ(押しっぱなしで連射にしない。連射が要る作品は、連射の間隔をつまみにして足す)。
- 入力を `window` だけで受けない(`AGENTS.md`「知らないと必ず溶かす」)。音はどの入力の最初の 1 回でも鳴らせるようにする(`core/audio` の unlock)。
- 作品ごとに変えてよい(例: 照準が要るならマウスの位置・右スティック・タッチの位置)。ただし 3 つのどれかで遊べない状態にはしない。
- 確かめ方: キーボードだけ / タッチだけ(`?debug=1` で生イベントを見る)/ コントローラだけ、でタイトルから 1 回遊べるか。
